# Product Overview

MYukkuriVoice は、AquesTalk を利用した Mac OSX 向けの合成音声生成アプリケーションです。  
動画制作向けに調整されており、入力した日本語メッセージから音声ファイルを生成できます。

## Core Capabilities

- **音声生成**: AquesTalk1 / AquesTalk2 / AquesTalk10 ベースの音声再生・録音
- **設定管理**: 複数の声種プリセットを名前付きで保存・切替
- **マルチボイス**: 会話形式で複数メッセージをまとめて音声再生・録音
- **動画連携**: 生成した音声ファイルを動画編集ソフト（Final Cut Pro X など）にドラッグアンドドロップ
- **ユーザー辞書**: 語の読み方をカスタマイズできる辞書機能

## Target Use Cases

- 個人・非営利目的での動画制作（ゆっくり実況など）
- ニコニコ動画・YouTube 等への投稿動画のナレーション生成
- Final Cut Pro X を使った本格的な動画編集ワークフロー

## Value Proposition

- AquesTalk ネイティブライブラリとの密な統合による高品質な音声合成
- 動画制作に最適化されたワークフロー（連番保存、メッセージ保存、DnD 連携）
- macOS に特化した UX（タッチバー、キーボードショートカット、アプリ自動更新）
